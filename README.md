# resumeforge

Free resume builder with ATS templates, import/export, and a guided editor.

## ResumeForge — Free Resume Builder

A dark-themed marketing site with a full-featured resume builder.

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — platform overview, highlights, stats |
| `/features` | Full feature breakdown by category |
| `/how-it-works` | Step-by-step guide + FAQ |
| `/templates` | Template showcase with previews |
| `/about` | Mission, values, privacy policy |
| `/builder` | Resume editor with live preview |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Tech Stack

- React 19 + TypeScript + Vite
- React Router
- Tailwind CSS v4
